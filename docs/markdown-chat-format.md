# Markdown チャット保存形式

MyTimes の Markdown チャットは、ユーザーが自由に書く Markdown 本文と、チャット構造を表す保存形式を同じファイルに持つ。
そのため、チャット構造として予約する行は本文として保存する前にエスケープし、読み込み時に復元する。

## 予約行

チャット構造として扱う予約行は次の通り。

- `# YYYY-MM-DD`: 日付見出し
- `## HH:mm`: メッセージ時刻見出し
- `---`: メッセージ区切り線
- `` ``` `` / `~~~`: コードフェンス開始行

コードフェンスは開始記号と長さを保持し、閉じ判定は同じ記号かつ開始長以上で、後続が空白のみの行に限定する。

## エスケープ規則

ユーザー本文に予約行が出る場合、先頭の本文文字の直前に `\` を 1 つ追加して保存する。

例:

`````text
---
## 10:00
# 2026-05-26
````
`````

保存時:

`````text
\---
\## 10:00
\# 2026-05-26
\````
`````

既に `\---` のようにエスケープ済みに見える本文もユーザー入力として保持するため、保存時にさらに 1 段エスケープする。
読み込み時は 1 段だけ戻す。

## 可逆性

append と export は同じエスケープ処理を使う。
少なくとも次の性質を満たすこと。

```text
本文 -> Markdown 化 -> parse -> 本文
```

この可逆性は `markdown_chat` と `markdown_message_escape` のテーブルテストで確認する。
