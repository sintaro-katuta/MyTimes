# 要件定義

## アプリケーションの概要
- コンセプト
    - Obsidianの「白いキャンバス症候群」を解決する、エンジニア向けの摩擦ゼロ・ローカル分報チャットアプリ。
- obsidianなどのメモアプリだと作業に集中して、リアルタイムで思考を書き留めることができない
- そこで分報くらいの感覚で、気軽に思考を書き留められるアプリケーションを作りたい
  - メモ帳などを使うとドキュメントを作ろうとしてしまうため心理的ハードルが高い
  - 分報だとフォーマットを気にせずに思考を残すことができる

## 機能要件
- チャットUI入力(MUST)
  - 画面下部に常にフォーカスされたテキストエリアを配置
  - Enterキーで送信、Shift + Enterで改行
- タイムライン表示(MUST)
  - 送信したテキストを、下から上に積み上がるチャット形式で表示
  - 各メッセージにはタイムスタンプ（例: 10:32）を付与
- ノート自動生成(WANT)
  - アプリ起動時および日付変更時、指定されたローカルディレクトリに YYYY-MM-DD.md のファイルが存在するか確認し、無ければ新規作成する
  - 同期されているファイルがobsidianから変更されて場合、リアルタイムに反映される(WANT)
    - チャットの区切りとして「---」を使用する
- Markdown追記(WANT)
  - チャット送信時、Rust側で該当のデイリーノートの末尾に所定のフォーマット（※後述）でテキストを追記する
  - ファイル全体の上書き（Rewrite）は行わない
- 設定(MUST)
  - ディレクトリの設定
  - ノート名の編集
  - ノートの削除
- ユーザー(WANT)
  - ログイン・ログアウト

## 非機能要件
- データポータビリティ: 完全なローカル完結。アプリをアンインストールしても、Obsidianのディレクトリに綺麗なMarkdownが残る状態を絶対的に担保する。
- パフォーマンス: 思考を妨げないよう、起動速度と入力のレンダリング遅延を最小限に抑える。
