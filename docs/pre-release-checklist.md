# 公開前チェックリスト

v1 公開前に、動作、品質、公開手順を確認するためのチェックリスト。
Sprint 4 の公開判断では、このチェックリストの必須項目が完了していることを確認する。

## 実行コマンド

公開判断前に、ローカルまたは GitHub Actions で次のコマンドが成功していることを確認する。

```sh
npm ci
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo check --manifest-path src-tauri/Cargo.toml
npm run build
npm run tauri -- build --verbose
```

PR では最低限、次の確認を完了する。

```sh
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo check --manifest-path src-tauri/Cargo.toml
npm run build
```

`npm run tauri -- build --verbose` は時間がかかるため、公開候補の確認または `main` 取り込み後の GitHub Actions で必ず確認する。
