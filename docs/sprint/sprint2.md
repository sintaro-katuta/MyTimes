## 課題

MYT-40 の Markdown 入力改善は v1 必須の作業でした。
ただし、実装量が大きく、単一 issue として扱うには範囲が広すぎました。

今回の問題は、不要なスコープを入れたことではなく、タスク分解不足です。
入力欄のように広がりやすい作業は、着手前により細かい単位へ分ける必要があります。

分割例は以下です。

- 基本入力
- Markdown 装飾
- リンク入力
- コードブロック入力
- 引用入力
- 保存時の Markdown 安定化
- 表示と入力のずれの調整
