# 環境構築

## Rustのインストール

下記のコマンドでtauriのに必要なRustをインストールします。
パッケージマネージャのCargoも同時にインストールされます。
```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

インストール後、以下のコマンドを実行して環境変数を設定します。
```sh
source $HOME/.cargo/env
```

それぞれインストールされたか確認する
```sh
rustc --version
rustc 1.94.0 (4a4ef493e 2026-03-02)
cargo --version
cargo 1.94.0 (85eff7c80 2026-01-15)
```

## MacOSの依存パッケージのインストール

```sh
# Homebrewがインストールされていることを確認
brew --version
→ Homebrew 5.0.1
# 必要なパッケージをインストール 
brew install node 

# Xcodeコマンドラインツールをインストール 
xcode-select --install
```

## TauriのCliをインストール
```sh
npm install -g @tauri-apps/cli
```
