# DESIGN

## 概要

`src/components` には、メッセージ中心のノート / チャット UI を構成する Vue コンポーネントが定義されている。全体の方向性は、Slack のような情報密度を保ちつつ、ライトモードでも重く見えないガラス調の面表現を採用した軽量なインターフェースである。

このドキュメントは、各コンポーネントの見た目と役割、共通デザイントークン、実装上の注意点を整理したもの。

## デザイン方針

- ベースは `Noto Sans JP` を使った日本語向け UI。
- 配色はニュートラルグレーを基調に、主要アクションのみオレンジで強調。
- パネルやメッセージカードは半透明の背景、細い境界線、ぼかしでレイヤー感を出す。
- ダークモードは `prefers-color-scheme: dark` で同一トークンを差し替えて成立させる。
- 角丸は 8px を基準にしつつ、カードやモーダルは 14px から 20px まで拡張して柔らかさを持たせる。

## 共通トークン

トークン定義は `src/style.css` にある。

### Typography

- フォント: `Noto Sans JP`
- 基本文字サイズ: `--font-size: 16px`
- 入力欄文字サイズ: `--input-font-size: 14px`
- 文字色
- `--text-primary`: 主見出し、主要ラベル
- `--text-secondary`: 本文
- `--text-tertiary`: 補助情報、日時、プレースホルダー寄りの文字
- `--text-inverse`: 塗りつぶしボタン上の文字

### Color

- 主要アクション: `--bg-primary`
- 成功: `--bg-success`
- エラー: `--bg-error`
- 面
- `--surface-canvas`: 画面全体の背景
- `--surface-panel`: 白いカード / 入力コンテナ
- `--surface-input`: 入力面
- `--surface-toolbar`: ツールバー面
- `--surface-overlay`, `--surface-overlay-muted`: モーダルやガラス面
- 境界線
- `--border-default`: 通常の枠線
- `--border-subtle`: 半透明の繊細な枠線

### Effect

- `--shadow-soft`: 小さな浮き
- `--shadow-panel`: メッセージカード用の深めの影
- `--shadow-modal`: モーダル用の強い影
- `--focus-ring`: キーボードフォーカスのリング
- `--overlay-backdrop`: モーダル背面の暗幕

## コンポーネント別

### `Button.vue`

役割:
アクション実行用の汎用ボタン。

特徴:
- `color` props で `bg-primary` / `bg-success` / `bg-error` を切り替える。
- 横幅は `100%` 固定で、フォーム内やモーダル内の主操作を前提とした見た目。
- 角丸と文字サイズは共通トークンを利用。

現状の注意:
- クラス名を ``bg-${color}`` で組み立てているため、許可する色の種類は実質固定。
- disabled、size、outline などのバリエーションは未定義。

### `Input.vue`

役割:
検索用の単一入力フィールド。

特徴:
- 左側に検索アイコンを固定配置。
- 入力面はフラットではなく、背景色だけでやわらかく区切る設計。
- パディングを広めに取り、タッチ操作でも窮屈に見えない。

見た目のポイント:
- アイコンは `16px`、入力左余白は `44px`。
- 文字色は `--text-tertiary` を使い、検索バーとして主張を抑えている。

### `Icon.vue`

役割:
アバターやサムネイルの簡易表示。

特徴:
- `src` があれば画像を表示。
- `src` がなければ `placeholder.svg` をマスクしたプレースホルダーを表示。
- デフォルトサイズは `48px x 48px`。

現状の注意:
- `defineProps` には `color` が明示されていないが、フォールバック描画側では参照している。
- プレースホルダーのサイズ指定は呼び出し側ではなく CSS 依存になりやすいため、利用時は表示確認が必要。

### `Message.vue`

役割:
メッセージ一覧の 1 行を表すカード。

特徴:
- 左にアバター、中央に本文、右上にホバー時のみ現れるアクション群を持つ。
- 背景は `color-mix` と `backdrop-filter` を使った半透明ガラス表現。
- 名前、日時、本文で情報階層を明確化している。

見た目のポイント:
- カードは `16px` 角丸、`18px 20px` の余白。
- 本文は `15px`、`line-height: 1.6` で可読性を優先。
- アクションは通常非表示で、ホバー時にフェード + 上下移動で出現。

インタラクション:
- `.message:hover .message-actions` で操作ボタンを表示。
- モバイルでは本文領域の右余白を解除して窮屈さを軽減。

現状の注意:
- アクションに `Heart` アイコンが 3 つ並んでいるが、意味づけはまだ入っていない。
- アバター画像は設定値から `/user-icon/default-user-icon.svg` を表示する。

### `SendMessage.vue`

役割:
メッセージ投稿欄。

特徴:
- 上段に書式ツールバー、下段に自動伸長するテキストエリア、その下に補助アクションと送信ボタンを配置。
- エディタというより「軽い投稿 composer」に寄せた設計。
- 面の切り替えで、ツールバーと本文入力部を視覚的に分離している。

見た目のポイント:
- 外枠は `16px` 角丸、`surface-panel` 背景。
- ツールボタンは `30px` 正方形、補助アクションは円形、送信ボタンは `36px` の角丸矩形。
- 送信ボタンのみブランドカラーで強く強調。

インタラクション:
- テキストエリアは入力内容に応じて高さが自動調整される。
- ボタン押下時は `scale(0.97)` で軽く沈む。
- hover は背景色中心の穏やかな変化で、騒がしくしない。

現状の注意:
- `var(--surface-subtle)` を参照しているが、`src/style.css` には定義がない。
- 書式ツールは見た目のみで、編集機能自体はまだ接続されていない。
- 送信処理、添付処理、ショートカットは未実装。

### `Modal.vue`

役割:
オーバーレイ表示用の共通モーダル。

特徴:
- `v-model` で開閉制御。
- `header` / `body` / `footer` のスロットを持ち、レイアウトだけを共通化。
- 背景はぼかし付きの暗幕、コンテンツは半透明グラデーション面で表示。

見た目のポイント:
- 最大幅は `680px`、画面高さに応じて `max-height` を持つ。
- 閉じるボタンは右上に浮いた円形ボタンとして配置。
- ヘッダーとフッターには境界線を引き、本文を中立的な読み領域として扱う。

インタラクション:
- 背景クリックで閉じる。
- 開閉時はフェード + `translateY` + `scale` の組み合わせで出入りする。
- `focus-visible` に専用リングを持ち、キーボード操作にも配慮している。

### `HelloWorld.vue`

Vite 初期テンプレート由来のサンプルであり、現行デザインシステムの一部としては扱わない。

## レイアウト上の想定

`src/App.vue` のサンプル配置から、以下のような使い方を想定している。

- `Message` を縦に積んだ一覧
- `SendMessage` を一覧下部または固定入力欄として設置
- `Input` を一覧上部の検索 / フィルタ導線に利用
- `Modal` をノート作成や詳細表示に利用

つまり、単体コンポーネント群というより、軽量なメッセージング UI を構成する部品セットになっている。

## 現状の実装メモ

- トークン設計はすでにある程度統一されているが、未定義変数 `--surface-subtle` が残っている。
- `Button.vue` は動的クラス依存のため、テーマ拡張時はバリアント API を整理した方が安全。
- `Icon.vue` は props 定義と利用値にずれがあるため、型付き props に寄せる余地がある。
- `Message.vue` のアクション群は UI モック段階で、機能名やイベント仕様は未確定。

## 今後の拡張候補

- `Button` に `variant`、`size`、`disabled` を追加
- `Input` に `modelValue`、`placeholder`、`icon` の外部指定を追加
- `Message` にアクション定義を props 化し、既読 / お気に入り / 編集などへ拡張
- `SendMessage` に実際の markdown / rich text 操作を接続
- `Modal` にフォーカストラップと ESC 閉じを追加
